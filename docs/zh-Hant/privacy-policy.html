1. 前言

「がぞうみまもり | Xセンシティブ画像フィルター」（以下稱「本擴充功能」）是一款 Chrome 擴充功能，用於在使用者的瀏覽器內判定 X（原 Twitter）時間軸和私訊中可能令人不適或含有露骨內容的圖片，並依需要將其隱藏。

本頁面說明本擴充功能會處理哪些資訊，以及這些資訊會如何被處理。

關於本擴充功能的功能概要，請參閱 📖 がぞうみまもり 介紹資料（PDF）。

關於使用方法，請參閱 📖 使用手冊。

2. 我們處理的資訊

本擴充功能會處理以下資訊。

資訊類型 用途 外部傳送
X 上顯示的圖片資料 用於判斷圖片是否可能令人不適或含有露骨內容；僅在瀏覽器內處理 無
擴充功能設定
（啟用/停用狀態、判定閾值和靈敏度）		 儲存至 Chrome 的同步儲存空間 無

3. 我們不會蒐集的資訊

本擴充功能不會蒐集、記錄或傳送以下資訊。

  • 姓名、電子郵件地址、住址等可識別個人身分的資訊
  • X 帳號資訊或登入憑證
  • 瀏覽紀錄、貼文內容或私訊內容
  • 經過判定的圖片資料本身
  • 判定結果、分數或相關記錄

4. 資訊的處理方式

本擴充功能的所有處理都在使用者的瀏覽器（Chrome）內完成。

  • 圖片判定透過瀏覽器內的 Offscreen Document API 執行
  • AI 模型（NSFWJS / TensorFlow.js）會載入到瀏覽器內，並在本機進行推論
  • 不會使用外部 API 或外部伺服器進行圖片處理或圖片判定
  • 判定結果僅用於控制畫面顯示，不會被儲存或傳送
  • 圖片本身、判定結果、分數和瀏覽紀錄不會儲存或傳送到開發者伺服器
  • 設定值（啟用/停用狀態、靈敏度等）會儲存到 Chrome 的 storage.sync

5. 向第三方提供資訊

本擴充功能不會向任何第三方提供、出售或分享資訊。

6. 使用的權限

本擴充功能要求的 Chrome 權限及其使用理由如下。

權限 理由
storage 用於在瀏覽器中儲存啟用/停用狀態和靈敏度設定
offscreen 用於在背景執行 AI 圖片判定
主機存取
（x.com / twitter.com / pbs.twimg.com）		 用於取得並判定 X 上顯示的圖片

7. 安全性

本擴充功能遵循 Chrome 擴充功能 Manifest V3。其 Content Security Policy（CSP）禁止 eval 和外部指令碼的執行。所有程式碼都在程式碼倉庫中公開，任何人都可以查看。

  • 原始碼：GitHub 倉庫

8. 兒童隱私

本擴充功能並非面向 13 歲以下兒童的服務。本擴充功能不會有意蒐集 13 歲以下兒童的個人資訊。

9. 隱私權政策的變更

本隱私權政策可能會在不另行通知的情況下進行變更。如有變更，將更新本頁面頂部的「最後更新」日期。重要變更也可能會在程式碼倉庫的 README 中說明。
