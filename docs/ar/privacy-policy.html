1. مقدمة

“がぞうみまもり | Xセンシティブ画像フィルター” (ويشار إليها في هذه الصفحة باسم "الإضافة") هي إضافة Chrome تكتشف تلقائيا الصور غير المريحة أو الحساسة أو ذات المحتوى الصريح المعروضة في الخط الزمني والرسائل المباشرة على X (تويتر سابقا) وتحظرها.

توضح هذه الصفحة المعلومات التي تتعامل معها الإضافة وكيفية التعامل مع تلك المعلومات.

للاطلاع على نظرة عامة عن الإضافة، يرجى مراجعة 📖 ملف PDF التعريفي بـ Gazou Mimamori.

للحصول على تعليمات استخدام الإضافة، يرجى مراجعة 📖 دليل الاستخدام.

3. المعلومات التي لا نجمعها

لا تجمع الإضافة المعلومات التالية ولا تسجلها ولا ترسلها.

  • المعلومات التي يمكن أن تحدد هويتك شخصيا، مثل الاسم أو عنوان البريد الإلكتروني أو عنوان المنزل
  • معلومات حسابك على X أو بيانات تسجيل الدخول
  • سجل التصفح أو محتوى المنشورات أو محتوى الرسائل المباشرة
  • بيانات الصورة نفسها بعد الحكم عليها
  • سجلات نتائج الحكم أو الدرجات

4. كيف تتم معالجة المعلومات

تكتمل جميع العمليات التي تجريها الإضافة داخل متصفحك (Chrome).

  • يعمل تقييم الصور داخل المتصفح باستخدام Offscreen Document API
  • يتم تحميل نموذج الذكاء الاصطناعي (NSFWJS / TensorFlow.js) في المتصفح ويجري الاستدلال محليا
  • لا تتم معالجة الصور باستخدام API خارجي أو خادم خارجي
  • تستخدم نتائج الحكم فقط للتحكم فيما يعرض على الشاشة، ولا يتم حفظها أو إرسالها
  • تحفظ الإعدادات (حالة التفعيل/التعطيل والحساسية ولغة العرض) في Chrome storage.sync

5. الإفصاح لأطراف ثالثة

لا تقدم الإضافة المعلومات إلى أي طرف ثالث ولا تبيعها ولا تشاركها.

7. الأمان
