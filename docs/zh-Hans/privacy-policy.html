1. 前言

「がぞうみまもり | Xセンシティブ画像フィルター」（以下简称“本扩展程序”）是一款 Chrome 扩展程序，用于在用户的浏览器内判断 X（原 Twitter）时间线和私信中可能令人不适或含有露骨内容的图片，并根据需要将其隐藏。

本页面说明本扩展程序会处理哪些信息，以及这些信息会如何被处理。

关于本扩展程序的功能概要，请参阅 📖 がぞうみまもり 介绍资料（PDF）。

关于使用方法，请参阅 📖 使用手册。

2. 我们处理的信息

本扩展程序会处理以下信息。

信息类型 用途 外部发送
X 上显示的图片数据 用于判断图片是否可能令人不适或含有露骨内容；仅在浏览器内处理 无
扩展程序设置
（启用/停用状态、灵敏度阈值和显示语言）		 保存到 Chrome 的同步存储中 无

3. 我们不会收集的信息

本扩展程序不会收集、记录或发送以下信息。

  • 姓名、电子邮件地址、住址等可识别个人身份的信息
  • X 账号信息或登录凭据
  • 浏览历史、帖子内容或私信内容
  • 经过判断的图片数据本身
  • 判断结果、分数或相关日志

4. 信息的处理方式

本扩展程序的所有处理都在用户的浏览器（Chrome）内完成。

  • 图片判断通过浏览器内的 Offscreen Document API 执行
  • AI 模型（NSFWJS / TensorFlow.js）会加载到浏览器内，并在本地进行推理
  • 不会使用外部 API 或外部服务器进行图片处理或图片判断
  • 判断结果仅用于控制屏幕显示，不会被保存或发送
  • 图片本身、判断结果、分数和浏览历史不会保存或发送到开发者服务器
  • 设置值（启用/停用状态、灵敏度和显示语言）会保存到 Chrome 的 storage.sync

5. 向第三方提供信息

本扩展程序不会向任何第三方提供、出售或共享信息。

6. 使用的权限

本扩展程序请求的 Chrome 权限及其使用理由如下。

权限 理由
storage 用于在浏览器中保存扩展程序的启用/停用状态、灵敏度设置和显示语言设置
offscreen 用于在后台执行 AI 图片判断
主机访问
（x.com / twitter.com / pbs.twimg.com）		 用于获取并判断 X 上显示的图片

7. 安全性

本扩展程序遵循 Chrome 扩展程序 Manifest V3。其 Content Security Policy（CSP）禁止 eval 和外部脚本的执行。所有代码都在代码仓库中公开，任何人都可以查看。

  • 源代码：GitHub 仓库

8. 儿童隐私

本扩展程序并非面向 13 岁以下儿童的服务。本扩展程序不会有意收集 13 岁以下儿童的个人信息。

9. 隐私政策的变更

本隐私政策可能会在不另行通知的情况下进行变更。如有变更，将更新本页面顶部的“最后更新”日期。重要变更也可能会在代码仓库的 README 中说明。
