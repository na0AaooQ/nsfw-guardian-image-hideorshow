1. 소개

“がぞうみまもり (Gazou Mimamori) | X 민감한 이미지 필터”(이하 “본 확장 프로그램”)는 X(구 Twitter)의 타임라인 및 다이렉트 메시지에 표시되는 불쾌감을 줄 수 있거나 노골적인 이미지를 자동으로 감지하여 차단하는 Chrome 확장 프로그램입니다.

이 페이지에서는 본 확장 프로그램이 취급하는 정보와 그 처리 방법을 안내합니다.

본 확장 프로그램의 기능 개요는 📖 がぞうみまもり 소개 자료(PDF)를 참조해 주세요.

본 확장 프로그램의 사용 방법은 📖 사용 설명서를 참조해 주세요.

3. 수집하지 않는 정보

본 확장 프로그램은 다음 정보를 수집, 기록 또는 전송하지 않습니다.

  • 이름, 이메일 주소, 주소 등 개인을 식별할 수 있는 정보
  • X 계정 정보 또는 로그인 정보
  • 열람 기록, 게시물 내용 또는 다이렉트 메시지 내용
  • 판정 후의 이미지 데이터 자체
  • 판정 결과 또는 점수의 로그

4. 정보 처리 방법

본 확장 프로그램의 모든 처리는 사용자의 브라우저(Chrome) 내부에서 완료됩니다.

  • 이미지 판정은 브라우저 내에서 Offscreen Document API를 사용하여 실행됩니다.
  • AI 모델(NSFWJS / TensorFlow.js)은 브라우저에 로드되어 로컬에서 추론을 수행합니다.
  • 이미지 처리를 위해 외부 API 또는 외부 서버를 사용하지 않습니다.
  • 판정 결과는 화면 표시 제어에만 사용되며 저장되거나 전송되지 않습니다.
  • 설정값(활성화/비활성화 상태 및 민감도)은 브라우저의 Chrome storage.sync에 저장됩니다.

본 확장 프로그램은 어떠한 제3자에게도 정보를 제공, 판매 또는 공유하지 않습니다.
